## 复现方式

1. 从附件建立节点表、边表、天气表和参数表。
2. 实现统一状态 `x_t=(t, v_t, w_t, f_t, m_t)` 与动作转移。
3. 运行确定型图动态规划并输出逐日资金/资源审计表。
4. 用回溯或独立 MATLAB 实现交叉验证。
5. 将确定型模型升级为 MDP，并做蒙特卡洛风险评价。

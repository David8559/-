# B078 核心算法实现说明

## 已实现

| 论文算法 | Python 实现 | 验证 |
|---|---|---|
| Floyd 任意两点最短路 | `floyd_warshall`、`reconstruct_path` | 距离与路径单元测试通过 |
| 不挖矿最少物资贪心 | `minimum_travel_requirements`、`solve_no_mining` | 第一关水 42、食物 38、剩余资金 `9410` |
| 含挖矿回溯搜索 | `solve_mining_backtracking` | 第一关复现 `10470` |

| 逐日结果导出 | `run_b078.py` | 输出 `b078_first_level_strategy.csv` |

## 第一关输入

论文 C++ 附录把第一关 27 节点地图压缩为四个特殊节点：

| 内部索引 | 实际节点 | 类型 |
|---:|---:|---|
| 0 | 1 | 起点 |
| 1 | 15 | 村庄 |
| 2 | 12 | 矿山 |
| 3 | 27 | 终点 |

特殊节点距离矩阵：

```text
0 6 8 3
6 0 2 3
8 2 0 5
3 3 5 0
```

允许的决策方向与论文 `f[4][4]` 一致：起点可去村庄、矿山或终点；村庄可去矿山或终点；矿山可回村庄或去终点。

## 复现结果

| 情形 | 初始水 | 初始食物 | 到达日 | 剩余资金 |
|---|---:|---:|---:|---:|
| 不挖矿 | 42 | 38 | 3 | 9410 |
| 含挖矿最优 | 178 | 333 | 24 | 10470 |

含挖矿初始负重为 `178×3 + 333×2 = 1200 kg`，与论文附表一致。

## 回溯与剪枝

搜索状态为：日期、特殊节点、水、食物、现金、最近村庄可追溯补给的剩余负重。剪枝包括：

1. 超过期限、现金不足或负重不足立即停止。
2. 相同状态只保留现金更多的分支。
3. 即使以后每天挖矿也无法超过当前最优值时停止。
4. 资源不足时只允许从最近村庄的剩余容量按双倍价格补足；没有访问村庄时不能追溯购买。

## 结算口径

论文 C++ 在终点使用 `cash + water×price + food×price`，相当于余料按基准价全额计回；题面文字通常解释为半价退回。实现提供 `refund_rate` 参数：`1.0` 用于复现 B078 原代码，`0.5` 用于按题面规则审计。第一关最优解最终水和食物均为 0，因此两种口径都得到 `10470`。

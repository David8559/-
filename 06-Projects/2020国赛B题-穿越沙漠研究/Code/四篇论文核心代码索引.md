## B108

关联：[[B108-论文拆解]]

| 原附录模块 | 作用 | 整理状态 |
|---|---|---|
| `desert_game.py` / `strategy.py` | 游戏规则模拟与策略接口 | 规则已重构到 `src/desert_core.py` |
| C++ `desert_game_dp(...)` | 确定天气图动态规划 | 状态结构已整理，完整求解器待接入各关天气 |
| `simulation.py` | 第三、四关随机天气模拟 | 已索引，待加入 Monte Carlo 测试 |
| 博弈策略代码 | 第五、六关局部/静态博弈 | 已索引 |

核心状态为 `dp[day][position][water][food] = max cash`，并保存前驱状态用于回溯。主要转移：起点购买、村庄补给、原地停留、移动、矿山挖矿、终点结算。它是四篇中最适合作为统一动态规划主线的实现。

图数据必须分版本：扫描附录显示第一关 `num_of_points=27`、矿山 12、村庄 15；第二关 `num_of_points=64`、矿山 30/55、村庄 39/62。超长 `wmap` 初始化行被 PDF 页面右侧裁切，当前不能完整恢复。

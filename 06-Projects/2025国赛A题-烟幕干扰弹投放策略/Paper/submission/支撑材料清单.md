# 支撑材料清单

本压缩包对应“2025 国赛 A 题—烟幕干扰弹投放策略”的 2026 年赛后复现稿，不是 2025 年正式竞赛期间形成的原始提交记录。

## 文件结构

- `Code/src/`：问题 1—5 的运动学、完整圆柱遮蔽判据、优化与绘图源代码。
- `Code/tests/`：42 项轨迹、约束、区间并集、数值回归、蒙特卡洛复现和排版回归测试。
- `Code/outputs/`：问题 1—5 的 JSON 关键结果及 CSV 时间序列、收敛和候选库。
- `Data/Derived/`：按原始模板生成的 `result1.xlsx`、`result2.xlsx`、`result3.xlsx`。
- `Paper/figures/`：正文采用的 17 幅关键证据图，覆盖统一流程、场景几何、判据曲线、参数敏感性、优化收敛、排程、联合覆盖与蒙特卡洛分布。
- `Paper/Paper-Expert-36项审查.md`：paper-expert 逐项适配结果与不适用项说明。
- `AI工具使用详情.pdf`：工具、用途、关键交互、采纳与人工复核记录。
- `环境与结果摘要.txt`：运行环境、核心结果、复现命令与完整性摘要。

## 复现环境

- Windows 11
- Python 3.12.5
- NumPy 2.4.3
- Matplotlib 3.10.8

## 复现命令

```powershell
python -m unittest discover -s Code/tests -p 'test_*.py' -v
python Code/src/run_problem1.py --output-dir Code/outputs --figure-dir Paper/figures
python Code/src/run_problem2.py --output-dir Code/outputs --figure-dir Paper/figures
python Code/src/run_problem3.py --reuse-result --output-dir Code/outputs --figure-dir Paper/figures
python Code/src/run_problem4.py --reuse-result --output-dir Code/outputs --figure-dir Paper/figures
python Code/src/run_problem5.py --reuse-result --output-dir Code/outputs --figure-dir Paper/figures
python Code/src/run_paper_expert_validation.py --output-dir Code/outputs --figure-dir Paper/figures
```

如脚本不支持 `--reuse-result`，按对应脚本 `--help` 使用完整搜索模式；完整搜索耗时明显高于复算和重绘。

## 核心结果

| 问题 | 完整圆柱有效时长 |
|---|---:|
| 问题 1 | 1.391643 s |
| 问题 2 | 4.587672 s |
| 问题 3 | 6.401396 s |
| 问题 4 | 11.632853 s |
| 问题 5 | M1 13.000935 s；M2 10.637703 s；M3 6.687083 s；总计 30.325721 s |

问题 5 是所生成候选库上的可行数值下界，不宣称解析全局最优。问题 3 第三枚弹在严格完整圆柱判据下无新增有效时长，材料中未将其改写为正值。

论文正文共 25 页，包含 36 个独立编号公式和 17 幅图。除给出最终参数外，还记录了完整圆柱判据推导、变量重参数化理由、分层搜索流程、失败搜索对照、空间离散收敛、端点复核、多起点复算、灵敏度边界及 2000 轮执行误差压力测试。

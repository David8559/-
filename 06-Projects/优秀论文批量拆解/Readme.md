# 优秀论文批量拆解

## 项目目标

- 对全国大学生数学建模竞赛优秀论文进行标准化拆解。
- 按主要数学机制归入 A–F 六类，并保留次类别。
- 每篇论文生成一份独立 Obsidian Markdown 笔记。
- 提取论文结构、模型逻辑、求解思路、结果检验以及图表落点。
- 跳过代码、软件函数与实现细节。

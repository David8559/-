# Research Triage Guide

- [ ] 来源可访问且已记录
- [ ] 标题能说明内容，不使用 `未命名`、纯日期或下载序号
- [ ] 只指定一个 `category` 主分类
- [ ] 至少一个 `topic/*` 标签
- [ ] 已连接一个 Topic Hub
- [ ] 代码或数据注明运行环境、版本与许可证
- [ ] 内容未与现有笔记重复
- [ ] 清洗只调整结构和可读性，未删减或改写原意

完成后将清洗版移动到建议的 `04-Research` 目录，原始下载留存到项目结束或确认归档策略后再处理。

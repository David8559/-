# Web Clipper Setup

推荐模板：`98-AI-Context/Automation/数学建模-clipper.json`。

用户原始模板备份：`98-AI-Context/Automation/数学建模-clipper.original.json`。

在 Obsidian Web Clipper 扩展中打开 Templates，导入推荐 JSON，并选择当前 Vault。模板会把标题、来源、作者、发布时间、抓取时间、分诊状态、主分类和正文保存到 `00-Inbox/Downloaded`。模板不调用 AI，不总结、不删减、不改写观点；文件名会用 `safe_name` 过滤非法字符。

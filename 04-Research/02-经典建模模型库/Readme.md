## 调用顺序

1. 先选一个能解释的简单基线。
2. 明确数据、变量、单位、假设、目标与约束。
3. 使用 [[04-Research/03-建模算法源码库/Readme|03-建模算法源码库]] 的基础实现。
4. 先做可行性和小样本校验，再做误差、残差、敏感性或多随机种子验证。
5. 最后才扩展复杂模型，并记录复杂度换来的实际提升。

# 蒙特卡洛方法

## 解决什么

当概率、积分、风险或复杂系统输出难以解析计算，但给定一组随机输入即可完成一次仿真时，用独立或相关抽样估计目标量。例如失败概率 $\hat p=n^{-1}\sum I(Y_r\in F)$、期望、分位数和置信区间。

## 标准流程

明确随机变量及分布依据 → 选择采样方式 → 固定并记录种子 → 重复仿真 → 输出均值、标准差、分位数、失败概率和区间 → 随样本量检查收敛。稀有事件不能靠少量普通抽样，需要重要抽样或保守上界。

## 必做检验

- 区分“真实数据拟合的分布”和“人为压力测试分布”。
- 报告样本量、独立性、随机种子和置信区间；不能只给一条随机轨迹。
- 按 $N,2N,4N$ 比较估计稳定性；检查代码对极端输入和失败状态的处理。
- 仿真系统存在初始瞬态时设置预热期；相关输出应用批均值等方法估计误差。

## 论文表达

压力测试只能说明在所设分布下的稳健性，不能直接解释为真实成功概率。把输入假设、抽样器、统计量和置信区间写清，并保存机器可读结果。

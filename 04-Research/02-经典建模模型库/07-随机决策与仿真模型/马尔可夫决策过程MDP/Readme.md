# 马尔可夫决策过程 MDP

## 模型要素

MDP 用状态 $s$、动作 $a$、转移概率 $P(s'\mid s,a)$、即时回报 $r(s,a,s')$ 和折扣/终止条件描述序贯随机决策。状态必须包含影响未来的关键信息；若历史仍影响转移，应扩充状态或改用部分可观测模型。

有限折扣问题的最优值满足 Bellman 方程：
$$V^*(s)=\max_a\left[r(s,a)+\gamma\sum_{s'}P(s'\mid s,a)V^*(s')\right].$$

## 标准流程

定义状态和动作的物理含义 → 估计/设定转移与回报 → 确认终止、资源和不可行动作 → 用价值迭代、策略迭代或有限期动态规划求解 → 仿真策略 → 与固定规则策略比较。

## 必做检验

- 每个 $(s,a)$ 的转移概率非负且和为 1；终止状态和边界正确。
- 报告 Bellman 残差、迭代容差和收敛；用小状态手算样例验证。
- 对转移概率、奖励和折扣做敏感性；以多情景仿真报告收益和失败概率。
- 从数据估计转移时保留样本不确定性，避免把稀疏频数当真值。

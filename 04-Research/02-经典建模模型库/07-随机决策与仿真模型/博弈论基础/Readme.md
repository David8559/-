# 博弈论基础

## 何时使用

当一个主体的最优行动取决于其他主体的行动时，才需要博弈模型。最小定义包括参与者、策略集、支付函数、行动时序和信息结构；缺少任何一项，所谓“纳什均衡”都无法复核。

## 标准流程

识别合作/非合作、静态/动态、完全/不完全信息 → 构造支付并统一量纲 → 删除严格劣势策略 → 求纯策略或混合策略均衡 → 检查单方偏离是否提高收益 → 比较社会最优、均衡效率和机制改进。

## 必做检验

- 支付参数做敏感性，报告均衡是否唯一、是否发生跳变。
- 对候选均衡逐参与者做偏离检验，而非只看求解器输出。
- 多均衡时说明选择规则；有限理性或合作承诺必须进入假设。
- 若参与者其实由同一决策者统一控制，应建多目标优化而非伪造博弈。

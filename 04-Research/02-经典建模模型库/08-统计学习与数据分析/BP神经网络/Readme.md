# BP 神经网络

## 定位

BP 是用反向传播计算梯度、训练多层前馈网络的方法，不是单一网络结构。它可逼近复杂非线性关系，但数据少、噪声大或需要强解释时，线性回归、树模型、SVM 往往是更可靠的比赛基线。

## 标准流程

划分训练/验证/测试 → 只在训练集拟合标准化 → 设小型网络和基线 → 选择损失、优化器与学习率 → 早停 → 多随机种子重复 → 在锁定测试集只评价一次。分类报告交叉熵、混淆矩阵和类别指标；回归报告 MAE/RMSE、残差和误差分布。

## 必做检验

- 给出层数、节点、激活、学习率、批量、轮数、早停和随机种子。
- 画训练/验证损失，识别过拟合；同预算与简单模型比较。
- 用多种子报告均值与离散程度，不挑最好一次。
- 小样本下限制网络规模，并明确不确定性和解释性不足。

## 论文边界

不能用“神经网络拟合能力强”替代模型选择理由，也不能把训练集高精度当泛化证据。若无独立验证或数据量不足，应把 BP 作为敏感性/候选模型，而非唯一结论来源。

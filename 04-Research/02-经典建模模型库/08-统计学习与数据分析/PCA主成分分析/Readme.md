# PCA 主成分分析

## 解决什么

把相关的数值变量投影到少数正交方向，在尽量保留方差的同时降维、去共线性或构造综合特征。中心化数据矩阵 $X$ 后，对协方差矩阵做特征分解，或直接用 SVD 得到载荷 $V$ 和得分 $Z=XV$。

## 适用边界

PCA 只利用线性相关和方差；“方差大”不等于“对任务重要”。量纲差异大时通常用相关矩阵/标准化数据；变量同量纲且方差本身有意义时可用协方差矩阵。类别标签不得参与无监督 PCA 的拟合。

## 标准流程与检验

缺失/异常审计 → 训练集中心化或标准化 → SVD → 用累计解释方差、碎石图和任务表现选择维数 → 解释载荷与符号 → 在验证集使用同一变换。报告解释方差率、保留维数、主要载荷和重构误差；用重抽样检查载荷子空间稳定性。

## 常见错误

- 在全数据上拟合 PCA 后再划分训练测试，造成泄漏。
- 仅凭“累计贡献率超过 85%”机械定维，不检查下游任务和解释性。
- 把主成分线性组合直接命名为现实概念，却没有载荷证据。

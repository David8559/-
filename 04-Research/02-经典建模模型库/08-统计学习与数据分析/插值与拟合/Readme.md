# 插值与拟合

## 先区分任务

插值要求曲线通过给定节点，适合区间内补值；拟合允许残差，以估计总体关系、降噪或预测。带噪观测不宜强制高阶插值，区间外预测也不能由“过点”保证可靠。

## 方法选择

- 分段线性：稳健、可解释，适合快速基线。
- 三次样条/PCHIP：平滑或保持单调，适合区间内曲线重建。
- 线性/非线性最小二乘：函数族有机理或经验依据时使用。
- 正则化/平滑样条：在拟合误差与曲线复杂度之间权衡。

## 必做检验

画散点与残差；留点或交叉验证比较模型；报告 RMSE/MAE 和参数区间；检查边界振荡、异方差和高杠杆点。外推时必须单列范围和机理依据。插值节点重复、排序错误或横坐标过近会造成数值不稳，应检查条件数或改用分段方法。

## 论文表达

说明选择函数族的理由、参数估计方式、误差指标、验证区间和外推限制。不要只写“使用 MATLAB 拟合工具箱得到曲线”。代码入口优先使用 `numpy.polyfit`、`scipy.interpolate`、`scipy.optimize.curve_fit`，并保存节点和参数。

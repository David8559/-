# 非线性规划

## 解决什么

在连续决策变量下，最小化非线性目标 $f(x)$，并满足非线性约束 $g_i(x)\le0$、$h_j(x)=0$ 和边界 $l\le x\le u$。适合几何设计、参数标定、连续调度和轨迹优化；若变量含整数或目标不连续，应转向混合整数或黑箱优化。

## 建模与求解

1. 先给变量定尺度、单位和物理边界；把可行性写成独立函数。
2. 用规则方案或网格搜索产生可行基线与初值。
3. 平滑中小规模问题优先 SLSQP、内点或信赖域；多峰问题采用多初值，必要时用全局搜索找种子、局部算法精修。
4. 报告求解状态、目标值、最大约束违反量、迭代/评估次数；不能只打印决策向量。

若满足约束资格条件，局部最优点可用 KKT 条件检查：$\nabla f(x)+\sum_i\lambda_i\nabla g_i(x)+\sum_j\nu_j\nabla h_j(x)=0$，并满足原始可行、对偶可行与互补松弛。KKT 通常只是局部必要条件，不自动证明全局最优。

## 必做检验

- 对变量缩放和初值做敏感性；至少进行多初值复算。
- 高精度重新计算约束，不接受“罚函数值很好但原问题不可行”。
- 与规则、随机、线性放松或解析上下界比较。
- 对临界解做边界两侧扰动；非光滑目标不要伪报梯度收敛。

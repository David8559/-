# 公共复用模块

从已完成项目中提炼、与具体赛题参数解耦的基础算法。完成项目继续保留自包含代码快照，避免赛后重构破坏复现；新项目优先从本目录复制或导入经过测试的公共实现，再在项目内固定版本。

## 已提炼模块

| 模块 | 可复用能力 | 项目来源 | 验证 |
|---|---|---|---|
| `mm_common.intervals` | 区间并、并集测度、多并集交集、删除边际 | 2025 A 题问题 3—5 | 合成边界与重叠案例 |
| `mm_common.roots` | 保持括区间的确定性二分求根 | 2024 A 题弧长/弦长反演；2025 A 题事件时刻 | 解析根、端点根、错误括区间 |
| `mm_common.optimization` | 单位立方体差分进化、可行性过滤、incumbent guard、坐标精修 | 2025 A 题问题 2—5 | 固定种子、已知最优点、约束与保优 |
| `mm_common.validation` | 统一报告不等式、等式和边界最大违反量 | 2024 A 题残差审计；2025 A 题可行性审计 | 分量与容差案例 |

## 运行验证

在 Vault 根目录执行：

```powershell
$env:PYTHONPATH='04-Research/03-建模算法源码库/00-公共复用模块/Python'
python -m unittest discover -s '04-Research/03-建模算法源码库/00-公共复用模块/Python/tests' -p 'test_*.py' -v
```

依赖为 Python 3.10+ 与 NumPy。测试记录写入 [[代码验证报告]]；代码通过本目录测试只证明公共函数在所列基准上正确，不自动验证任何具体赛题。

## 调用约束

1. 项目固定公共模块的提交哈希或复制快照，不能直接依赖会变化的 Vault 文件。
2. 区间默认闭区间，容差与时间单位必须由项目明确。
3. 优化器只返回数值候选；项目仍须高精度复算约束、报告基线和多种子结果。
4. 二分法要求连续函数且端点异号；离散跳变或切点根应使用其他事件检测方法。

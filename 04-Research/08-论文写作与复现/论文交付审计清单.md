# 论文交付审计清单

> [!summary] 使用定位
> 论文交付前逐项勾选的量化验收清单。合并四组来源：**A 官方合规**（2026 电子稿口径）、**B 五轮检查**（论文写作 Hub）、**C 36 项格式类**（Paper-Expert 格式相关项）、**D 交付包审计**（Stage-Gates 阶段 G 实测项与支撑材料）。✅ 表示可由脚本/管线自动检查，👤 表示需人工检查。不满足 A 组任意一项视为阻断；B/C/D 组按项记录结果，阻断项必须修复后重审。

## A 官方合规（2026 电子稿口径）

| # | 检查项 | 判定标准 / 查法 | 方式 |
|---|---|---|---|
| A1 | 电子版第一页为摘要专用页 | 第一页=标题+摘要+关键词，一页内；不含承诺书、编号页 | ✅脚本（PDF 首页文本）+👤目视 |
| A2 | 承诺书/编号专用页不入电子版 | 文档中无承诺书、编号页内容 | ✅脚本（关键词扫描） |
| A3 | 页码从摘要页起编=1，全文连续 | 单节+PAGE 域；渲染后页码 1 起连续 | ✅脚本（docx 域检查）+👤目视 |
| A4 | 无目录 | 正文无目录页/域 | ✅脚本（TOC 域/关键词扫描） |
| A5 | 正文不超过 30 页 | 正文（不含摘要页）页数 ≤30 | 👤（需渲染，列入 skill 已知限制） |
| A6 | A4 页面、页边距 ≥2.5 cm | 页面尺寸与边距常量一致 | ✅脚本（python-docx 读取） |
| A7 | 正文样式统一 | 字体（宋体/TNR 10.5pt）、行距（1.18）、首行缩进（0.74cm）、标题层级一致 | ✅脚本（样式枚举）+👤抽查 |
| A8 | 公式可编辑、编号连续、版面统一 | 无公式图片（正文公式非截图）；编号 (1)(2)(3) 连续；居中、编号右对齐 | ✅脚本（编号正则）+👤目视 |
| A9 | 三线表，表题在上；图题在下 | 表格无竖线（或按项目样式）；题注位置正确 | 👤目视（渲染后） |
| A10 | 图表有轴标注/单位/图例并被正文引用 | 每个图表被引用（"如图 N 所示"）；轴标签含物理量+单位 | ✅脚本（引用交叉检查）+👤目视 |
| A11 | 参考文献规范 | 正文逐处引用、列表双向对应；GB/T 7714；≥10 篇；无百科引用 | ✅脚本（双向对应）+👤抽查格式 |
| A12 | 附录含支撑材料清单+全部完整可运行源码 | 附录列出文件清单、运行说明；源码完整可运行且与 ZIP 同版本 | ✅脚本（清单 vs 实际文件）+👤抽查 |
| A13 | 支撑材料 ZIP ≤20MB、入口可运行 | 文件大小、入口脚本存在、无依赖未打包绝对路径 | ✅脚本（大小+路径扫描） |
| A14 | AI 使用披露 | 正文标注 AI 辅助位置；独立 AI 工具使用详情（工具、用途、采纳情况） | ✅脚本（标注存在性）+👤内容核对 |
| A15 | 匿名性 | docx/PDF 元数据、路径、文件名无用户目录编号或身份信息 | ✅脚本（元数据+字符串扫描） |
| A16 | 论文/支撑材料数值版本一致 | 正文、附录、代码输出、结果表同一版本同数值 | ✅脚本（关键数值交叉）+👤抽查 |

## B 五轮检查（论文写作 Hub）

| # | 检查项 | 判定标准 / 查法 | 方式 |
|---|---|---|---|
| B1 | 五问逐一直接作答 | 每问有直接回答问题的结果小节，最终答案正文醒目标出 | 👤 |
| B2 | 摘要、正文、表格、代码结果一致 | 关键数值四处一致（数字+单位+精度） | ✅脚本（数值交叉）+👤 |
| B3 | 每个关键数字可追溯 | 数字能追溯到脚本、参数、数据与验证记录 | 👤（抽查关键数字） |
| B4 | 无虚构数据/实验/引用 | 数值均有来源；模型假设明确标注；无"模型较优""精度很高"等无证据表述 | ✅脚本（禁语扫描）+👤 |
| B5 | 假设、符号、公式、算法、结果、检验闭环 | 假设→符号→公式→求解→检验→结论链路完整可查 | 👤 |
| B6 | 每问五层闭环（概念/数学/推导/求解/解读） | 各问五层要素齐全，无缺层 | 👤 |
| B7 | 跨问题递进关系显式标注 | 后问开头指出前问输出作为输入/约束/初值 | ✅脚本（衔接关键词）+👤 |
| B8 | 一般性策略有适用条件 | 策略段落含适用条件、阈值、失效情形，非单个算例包装 | 👤 |
| B9 | 格式检查（匿名、标题层级、图表公式编号、引用、附录） | 与 A 组一致；标题能看出"对象—方法—结果"推进 | ✅脚本+👤 |
| B10 | 统一性（术语、符号、语气一致） | 全文同一术语/符号/语气，无一人多稿痕迹 | 👤 |

## C 36 项格式类（Paper-Expert）

| # | 检查项 | 判定标准 / 查法 | 方式 |
|---|---|---|---|
| C1 | 公式编号 (1)(2)(3) 全文连续 | 正则扫描，无 (1-1)/(1.1) | ✅脚本 |
| C2 | 公式居中、编号右对齐 | 渲染后版面一致 | 👤 |
| C3 | 符号表完整、下标上标系统化 | 核心符号均有定义，表与正文一致 | ✅脚本（符号表 vs 正文出现） |
| C4 | 图题在下、表题在上 | 题注位置 | 👤 |
| C5 | 图号/表号分开编制且连续 | 编号序列 | ✅脚本 |
| C6 | 每个图表被正文引用 | 双向交叉 | ✅脚本 |
| C7 | 图表轴标注（物理量+单位） | 逐图检查 | 👤 |
| C8 | 图表总数达标（≥10，15-25 最优） | 计数 | ✅脚本 |
| C9 | 页码统一（底部居中/顶部右对齐） | 渲染后位置 | 👤 |
| C10 | 字体统一（标题黑体、正文宋体+TNR、小四） | 样式扫描 | ✅脚本 |
| C11 | 标点一致（中文全角、英文半角） | 混用扫描 | ✅脚本 |
| C12 | 行距统一 | 样式扫描+目视 | ✅脚本+👤 |
| C13 | 假设合理且标注理由 | 每条含合理性与失效影响 | 👤 |
| C14 | 关键词 4-6 个、含方法类 | 计数与构成 | ✅脚本+👤 |
| C15 | 文献 ≥10 篇、含英文、GB/T 7714、无百科 | 统计+格式抽查 | ✅脚本+👤 |

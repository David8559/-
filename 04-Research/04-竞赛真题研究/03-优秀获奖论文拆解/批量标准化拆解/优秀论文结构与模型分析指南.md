## 1 优秀论文的通用结构

1. 摘要：按“子问题—模型—求解—关键结果—检验”压缩，必须出现定量结果或明确结论。
2. 问题重述与分析：把自然语言任务改写成输入、决策变量或状态变量、约束、目标与输出。
3. 模型假设：只保留会改变方程、约束、数据口径或结论边界的假设。
4. 符号说明：统一符号、含义、单位和取值域，避免同一符号跨分问变义。
5. 分问建模：每问均说明为什么选该模型、如何从题意得到数学关系、如何求解、结果怎样回答问题。
6. 模型检验：至少包含误差、灵敏度、稳健性、样本外验证或极端情形检验中的一种。
7. 模型评价：优点必须对应具体机制，不足必须能导向可执行的改进。

## 2 A类 连续型模型

- 分析顺序：确定系统边界 → 画物理结构与坐标系 → 定义连续状态量 → 写守恒、传递或动力学关系 → 给出初值与边界条件 → 数值离散或解析求解 → 参数标定 → 灵敏度与误差分析。
- 核心检查：量纲是否一致；初边值条件是否充分；离散步长是否收敛；参数是否可辨识；解是否满足物理边界。
- 应画图处：问题分析后画结构、受力或控制体示意图；求解后画时间曲线、空间剖面、等值线或相图；检验处画步长收敛和参数扰动曲线。
- 应制表处：变量与单位表、初值/边界条件表、物理参数来源表、数值误差与实验对照表。

### A类可创新点

- 模型创新：由单一机理扩展到多物理场耦合、时变参数、非线性边界、随机扰动或分数阶/时滞机制；创新必须说明新增机制对应哪条现实规律。
- 数据与参数创新：用观测数据反演参数，引入区间估计、贝叶斯校准或数据同化，并报告参数可辨识性与不确定性。
- 求解创新：使用自适应步长、网格加密、降阶模型、代理模型或物理约束学习加速求解，同时给出精度—时间对比。
- 检验创新：增加守恒残差、网格无关性、极端边界、参数不确定性传播和实验/公开数据对照，而不只展示一条结果曲线。
- 图表创新：组合“物理结构图—状态场—误差场—不确定性带”，让机理、结果和可信度形成同一证据链。
- 容易形成的伪创新：只更换常微分方程求解器；没有物理理由地加入神经网络；只把常数改成函数却不重新标定。
- 可用表述：在原有守恒关系基础上，本文将“某一被忽略的机制”写入状态方程，并通过网格收敛与参数扰动实验验证新增机制对关键输出的影响。

## 3 B类 离散型模型

- 分析顺序：明确决策对象 → 定义 0-1、整数或路径变量 → 写目标函数 → 逐条把业务规则翻译为约束 → 判断图论、规划、调度或排队结构 → 求可行解与优化解 → 检查可行性、最优性和复杂度。
- 核心检查：变量是否完整覆盖决策；约束是否漏项或重复；目标与题意口径是否一致；算法结果是否可行；是否有基准解、上下界或多方案对比。
- 应画图处：抽象完成后画网络、路径、调度或选址示意图；算法处画状态转移或求解流程；结果处画路线图、甘特图、资源占用或收敛曲线。
- 应制表处：变量与约束表、参数表、分配/排班方案表、基准与优化方案对比表、约束满足情况表。

### B类可创新点

- 模型创新：把确定性模型扩展为动态、随机、鲁棒、多目标或双层规划；将临时中断、服务公平、碳排放、风险和应急恢复等现实约束显式写入。
- 数据创新：用历史订单、路况或到达过程估计需求和时间分布，再通过场景生成把预测不确定性传入优化模型。
- 求解创新：设计问题专用编码、邻域、有效不等式、分解策略或精确算法与启发式的混合框架，并说明为什么适配本题结构。
- 实时决策创新：采用滚动时域、事件触发重优化或在线插单机制，比较静态最优与动态调整的成本和稳定性。
- 检验创新：报告可行性审计、最优间隙或上下界、算法收敛、规模扩展性以及参数扰动后的方案变化。
- 图表创新：路线图、甘特图、资源占用图与 Pareto 前沿配合方案表，体现方案如何执行而不只给目标值。
- 容易形成的伪创新：只把遗传算法换成粒子群；只增加迭代次数；没有基线、最优间隙或可行性核验却宣称算法更优。
- 可用表述：针对原模型无法处理的动态约束，本文构建滚动优化框架，并用相同算例比较基线方案、改进方案的目标值、可行率和计算时间。

## 4 C类 数据分析与数据挖掘

- 分析顺序：说明数据来源与口径 → 清洗缺失、异常和重复值 → 探索分布与相关性 → 构造特征 → 划分训练/验证/测试集 → 建立简单基线 → 训练候选模型 → 用统一指标比较 → 解释误差与重要特征。
- 核心检查：是否存在数据泄漏；训练与测试是否同分布；指标是否适合类别不平衡或时间序列；模型提升是否超过简单基线；结论是否超出样本范围。
- 应画图处：数据理解阶段画缺失率、直方图、箱线图、散点图和相关热图；结果阶段画真实—预测、残差、混淆矩阵、ROC/PR 或特征重要性图。
- 应制表处：字段与口径表、清洗规则表、样本划分表、特征表、模型指标对比表、错误样本或稳健性结果表。

### C类可创新点

- 数据创新：融合多源、时空或外部数据，明确匹配口径；针对缺失机制、异常值和样本偏差设计处理方案，而不是简单删除。
- 特征创新：从业务机制构造交互、滞后、周期、空间邻接或结构性特征，并用消融实验验证每类特征的增量价值。
- 模型创新：采用分层、两阶段、集成、多任务或机理—数据融合模型；复杂模型必须相对简单基线获得稳定提升。
- 目标与指标创新：对类别不平衡、错误成本或预测区间重新设计损失和评价指标，并报告校准性与不确定性。
- 解释创新：使用局部/全局解释、误差分群、反事实或敏感性分析，把“预测得准”推进到“为什么、何时会失败”。
- 检验创新：采用嵌套交叉验证、时间滚动验证、空间留一验证、外部测试集和消融实验，专门检查数据泄漏与分布漂移。
- 图表创新：把数据质量、特征贡献、真实—预测、残差结构和失败样本放在一组图中，形成从数据到结论的审计链。
- 容易形成的伪创新：堆叠多个算法后只报告最高准确率；把调参称为模型创新；在全量数据上预处理后再划分训练集。
- 可用表述：本文从问题机制构造某类新特征，并通过统一数据划分下的基线对比与消融实验，验证该特征对精度、稳定性和解释性的独立贡献。

- 入口：[[论文模型分类-C类数据分析与数据挖掘]]。

## 5 D类 综合决策与评价

- 分析顺序：界定评价对象 → 建立指标层级 → 标注正向/负向与单位 → 无量纲化 → 计算主观或客观权重 → 综合评分与排序 → 权重扰动和方法替换检验。
- 核心检查：指标是否独立且不重复；标准化方向是否正确；AHP 一致性是否通过；熵权是否被极端离散度支配；排名对权重和归一化方式是否稳定。
- 应画图处：指标确定后画层次结构图；结果处画排序条形图、雷达图或二维定位图；稳健性处画权重扰动—名次变化图。
- 应制表处：指标定义与方向表、原始/标准化数据表、权重表、一致性检验表、综合得分与排序表、敏感性结果表。

### D类可创新点

- 指标创新：从作用机制而不是资料可得性出发构建指标；区分投入、过程、产出和风险，并用相关性或共线性检查删除重复指标。
- 权重创新：融合专家判断与客观数据，使用组合权重、区间权重或随时间变化的权重，并公开一致性与冲突处理规则。
- 聚合创新：比较 TOPSIS、VIKOR、DEA、模糊评价或秩聚合等不同补偿机制，解释为什么某种排序逻辑更符合题意。
- 不确定性创新：用蒙特卡洛权重扰动、秩可接受性或情景权重分析，输出排名区间和翻转阈值，而不是唯一确定名次。
- 外部验证创新：用历史结果、专家盲评或后续真实表现检验综合得分，判断评价体系是否具有预测或区分能力。
- 图表创新：用指标贡献图、权重—排名敏感性热图和排序稳定区间代替只画雷达图。
- 容易形成的伪创新：机械串联 AHP、熵权和 TOPSIS；指标越多越好；不给权重扰动却宣称排序客观稳定。
- 可用表述：本文将主观偏好与客观差异合成为区间权重，并通过多方法排序一致性和权重扰动实验给出排名稳定区间。

- 入口：[[论文模型分类-D类综合决策与评价]]。

## 6 E类 社会环境政策与系统仿真

- 分析顺序：识别利益相关者与系统边界 → 提出机制或指标框架 → 建立反馈、转移或情景模型 → 设置基准、乐观、悲观与政策情景 → 推演长期结果 → 比较收益、成本、公平和可持续性。
- 核心检查：政策变量是否可操作；情景参数是否有来源；短期与长期效应是否分开；反馈与滞后是否考虑；建议是否超出模型证据。
- 应画图处：问题分析后画利益相关者图、因果回路或系统边界；结果处画多情景演化曲线、空间分布图和政策权衡图。
- 应制表处：利益相关者诉求表、情景参数表、政策组合表、多情景结果与风险表。

### E类可创新点

- 系统边界创新：把过去分开处理的人口、经济、资源、生态和行为反馈纳入同一系统，同时明确不能建模的外部因素。
- 主体异质性创新：按地区、群体或机构区分行为规则，采用系统动力学、主体仿真或空间模型刻画政策影响的差异。
- 情景创新：情景由可解释的政策杠杆和参数组合生成，并覆盖基准、压力、转型和失效情景，而不是任意调整数值。
- 目标创新：同时衡量效率、公平、韧性、环境代价和长期可持续性，展示政策之间的权衡而非只求单一最优。
- 数据与参与创新：用公开统计、遥感、调查或利益相关者意见校准参数，并记录来源、冲突与不确定区间。
- 检验创新：进行历史回测、结构敏感性、情景压力测试和政策失效分析，说明建议在什么条件下不成立。
- 图表创新：使用因果回路、存量流量、多情景带、空间地图和政策权衡前沿形成“机制—推演—决策”链。
- 容易形成的伪创新：只建立指标体系就宣称政策仿真；主观设定情景参数；从相关关系直接推出因果政策建议。
- 可用表述：本文把可操作政策变量嵌入系统反馈结构，并通过历史回测与多压力情景比较政策效果、分配差异和失效边界。

## 7 F类 博弈与对策

- 分析顺序：确定参与者、策略集、信息结构和行动顺序 → 构造收益函数或支付矩阵 → 求最优反应与均衡 → 判断均衡存在性、唯一性和稳定性 → 做参数比较静态或策略演化分析。
- 核心检查：收益是否体现真实利益；同时或序贯行动是否区分；完全与不完全信息是否区分；均衡是否可实现；参数变化是否导致均衡切换。
- 应画图处：模型建立处画博弈树或参与者关系；均衡分析处画最优反应曲线、相图或策略比例演化图。
- 应制表处：参与者—策略—收益表、支付矩阵、参数条件—均衡类型表、不同制度下结果对比表。

### F类可创新点

- 结构创新：从完全信息静态博弈扩展到不完全信息、序贯、重复、演化或网络博弈，使行动顺序与信息差异符合现实。
- 收益创新：用真实成本、风险、声誉、学习效应和外部性构造收益，并利用数据或区间估计校准参数。
- 主体创新：引入异质偏好、有限理性、联盟形成或多层级委托关系，分析不同主体为什么采取不同策略。
- 机制设计创新：不只求现有规则下的均衡，还设计奖励、惩罚、信息披露或契约，使个体最优与整体目标更一致。
- 均衡分析创新：证明或数值检验均衡存在性、唯一性和稳定性，给出参数阈值、均衡切换与路径依赖。
- 检验创新：用历史事件、行为数据、仿真实验和比较静态验证收益设定，检查替代收益函数下结论是否保持。
- 图表创新：支付矩阵、博弈树、最优反应曲线、相图与制度对比表共同展示策略逻辑。
- 容易形成的伪创新：凭主观数字编支付矩阵；只求一个纳什均衡；把“多方参与”直接等同于使用博弈论。
- 可用表述：本文依据主体成本与信息差异重构收益函数，并设计某项激励机制，通过均衡稳定性和参数阈值分析验证制度效果。

- 入口：[[论文模型分类-F类博弈与对策]]。

## 8 图与表的选择规则

| 信息类型 | 优先形式 | 推荐位置 |
|---|---|---|
| 机制、流程、层级、空间关系 | 图 | 问题分析或模型建立之前 |
| 变量、单位、参数、约束、指标定义 | 表 | 对应模型公式之前 |
| 时间或空间变化、相关结构、模型拟合 | 图 | 求解结果之后 |
| 精确数值、方案、排序、误差、指标比较 | 表 | 结果分析段开头 |
| 敏感性、稳健性、多情景权衡 | 图表组合 | 模型检验部分 |

## 9 单篇论文复核顺序

1. 先读摘要，写出每问的模型、输出和关键结论。
2. 对照正文检查摘要是否遗漏关键约束、假设或失败条件。
3. 逐式检查变量定义、量纲、目标、约束和初边值条件。
4. 逐图表确认正文先引用、图表能独立读懂、结论与数据一致。
5. 检查是否真正做了灵敏度、稳健性或误差分析，而不是只给出模型优点。
6. 最后记录可复用写法与不可照搬的适用边界。

## 10 解析边界

- `embedded-text` 笔记使用 PDF 文本层，公式版式仍可能损坏。
- `selected-page-ocr` 笔记只覆盖代表页，未识别的中间页必须回到原 PDF 核对。
- 所有 `【解析缺失，人工补全】` 均为证据不足标记，不允许根据上下文编造。
- 本批笔记不提取代码，不解释软件函数或程序实现。

## 11 创新点使用与判定标准

1. 先写基线：说明常规做法或原模型不能处理什么，不先建立基线就不能证明改进。
2. 再写增量：明确新增变量、机制、数据、约束、算法或检验，禁止只写“采用先进方法”。
3. 给出证据：至少用基线对比、消融、误差、稳定性、计算时间或实际可行性中的一项验证增量。
4. 说明代价：复杂度、数据需求、参数数量和解释难度上升时，应写明收益是否值得。
5. 限定范围：竞赛论文中的“创新”通常是相对本题常规解法的组合与适配，不等同于经文献检索证明的学术首创。
6. 控制数量：正文突出一个主创新和一至两个支撑创新，比罗列五个模型名称更有说服力。

### 创新点最小证据表

| 创新声明 | 最低验证证据 |
|---|---|
| 新模型或新机制 | 与原模型的结构差异、参数来源、误差或解释增益 |
| 新特征或新数据 | 统一划分下的基线对比和消融实验 |
| 新算法 | 相同算例下的解质量、可行率、时间和规模表现 |

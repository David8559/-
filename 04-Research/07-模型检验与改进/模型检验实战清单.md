# 模型检验实战清单

> [!summary] 核心原则
> “程序运行成功”不是模型检验。可信结论至少需要数学/结构证据、数值证据、现实或外部证据中的两层；关键结论应能被反例、扰动或独立实现主动挑战。

## 三层证据

| 层 | 要回答的问题 | 常用方法 | 失败信号 |
|---|---|---|---|
| 数学与结构 | 公式是否对应题意、量纲和约束？ | 单位检查、守恒、不变量、边界、KKT、上下界、手算样例 | 单位不一致、约束方向错、不可行解被当最优解 |
| 数值与算法 | 离散、初值、随机性是否改变结论？ | 网格/步长收敛、多初值、多种子、残差、条件数、端点求根 | 只报一次运行、整数采样漏峰值、粗网格替代正式判据 |
| 现实与外部 | 结果是否能解释，是否与外部证据一致？ | 简单基线、历史数据、优秀论文对照、极端情形、专家规则 | 只因“接近他人结果”就判定正确、忽略定义不同 |

## 高频检验方法

### 1. 先审计量词和集合，再写聚合

多对象覆盖、可靠性和资源分配常在“对每个对象存在一个方案”与“存在一个方案适合所有对象”之间出错。先把量词写成公式，再构造一个最小反例验证代码。2025 A 题的多烟幕判据使用 $\forall P\,\exists k$，不能用 $\exists k\,\forall P$ 的单云团区间并集代替。

### 2. 连续极值不能只看整数采样

若目标由事件、碰撞、峰值或阈值决定，应先粗扫定位候选，再在连续区间求根或局部优化；报告临界点两侧的符号。2024 A 题的速度峰值和碰撞时刻都属于此类。

### 3. 优化先保可行，再谈最优

- 输出最大约束违反量和可行率；不可行个体不得凭罚函数分数进入候选库。
- 保留已验证可行解（incumbent guard）；低精度或随机候选只有在同一高精度判据下更优才能替换。
- 与规则、随机、放松问题或已知上/下界比较；“算法收敛”不等于“全局最优”。

### 4. 用删除复算和反事实代替口头归因

多部件、多变量模型应删除一个部件后完整复算，定义边际贡献 $\Delta_i=J-J^{(-i)}$。不能用“单独贡献为零”推出“联合贡献为零”；空间协同和非线性交互必须在联合判据中复算。

### 5. 随机仿真必须报告不确定性

固定并公开随机种子只是可复现条件，不是统计证据。至少报告重复次数、均值、标准差或置信区间、关键分位数、失败概率和随样本量的收敛；若输入分布是人为假设，结论只能解释为压力测试，不能当真实成功率。

## 按题型的最低证据包

| 题型 | 最低证据包 |
|---|---|
| 预测 | 朴素基线 + 时间/分层验证 + 残差 + 外推边界 |
| 评价 | 指标方向检查 + 替代权重 + 排名稳定性 + 相关性/冗余 |
| 优化 | 可行性 + 基线/上下界 + 多初值/多种子 + 约束敏感性 |
| 聚类/分类 | 标准化 + 稳定性 + 合适指标 + 解释性/类别不平衡 |
| 机理与几何 | 量纲/守恒 + 极端情形 + 网格/步长收敛 + 独立复算 |
| 仿真 | 预热期 + 重复次数 + 置信区间 + 随机种子 + 收敛 |

## 论文报告模板

> 在固定【数据版本/参数】下，以【简单基线】为对照；通过【检验一】确认【结构或数值性质】，再用【检验二】考察【扰动/随机性/离散误差】。核心指标由【基线】变为【结果】，最大约束违反/误差为【数值与单位】。因此结论在【范围】内成立；对【未验证条件】不作外推。

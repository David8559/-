# 模型检验 Hub

> [!summary] 定位
> 本 Hub 用于回答“为什么相信这个结论”，不是模型优缺点的套话集合。比赛时先打开 [[模型检验实战清单]]，按题型选择证据包，再把数值、参数、图表和适用边界写回项目。

## 快速选择

| 风险 | 优先检验 | 论文必须报告 |
|---|---|---|
| 公式或单位可能错 | 量纲、不变量、手算/合成样例 | 定义、单位、最大残差 |
| 离散化可能漏事件 | 网格/步长收敛、端点求根 | 分辨率、收敛差、临界两侧 |
| 优化停在次优或不可行 | 多初值、多种子、可行性、基线/上下界 | 预算、种子、约束违反、最优性边界 |
| 多对象逻辑复杂 | 量词审计、集合反例、删除复算 | 正式判据、反例、边际贡献 |
| 预测可能过拟合 | 留出/滚动验证、残差、泄漏审计 | 切分方式、基线、误差分布 |
| 随机结果不稳定 | 重复仿真、置信区间、分位数 | 样本量、种子、区间、失败概率 |
| 参数或权重主观 | 局部/全局敏感性、排序稳定性 | 扰动范围、敏感参数、结论变化 |

## 赛中最小流程

1. 写出核心结论及可能的反证方式。
2. 选择简单基线，确认方向、量纲和可行性。
3. 从 [[模型检验实战清单]] 选择至少两类独立证据。
4. 让代码自动输出残差、约束、参数、种子和检验图，不手抄数字。
5. 对失败检验保留记录；修正模型后重跑同一检验。
6. 论文明确“不支持哪些结论”和适用边界。

# User Preferences

- 主要领域：数学建模模型、方法、论文写作。
- 工具：Python、MATLAB。
- 主要输出：数学建模论文、源代码、源数据。
- 工作偏好：优先直接执行；给出验证结果；无法自动化时明确资料和手动步骤。
- 项目推进偏好：开始新的题目或阶段前，先说明目标、方法、交付物和风险，等待确认后再继续；用户对后续工作不熟悉时不得把一次“继续”自动扩展为全部后续阶段授权。
- 知识库节点偏好：按知识实体的独立价值决定是否建节点，而不是机械追求“少节点”。完整赛题、论文复现、可独立调用的算法案例、具有独立来源与验证链的研究成果必须建立可见实体节点；没有独有知识的分类 Readme、空日报、占位文件和重复索引不建或删除。能够直接丰富现有权威笔记且不需要独立检索、复现或引用的内容，优先并入原节点。
- 写作偏好：结论先行，数学符号一致，图表可解释，来源可追溯，代码可复现；正文应达到知识库优秀论文的解释密度，每问形成“题意转换—模型建立—算法求解—结果分析—检验与边界”闭环，不能只写成压缩的求解报告。

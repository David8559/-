# User Preferences

- 主要领域：数学建模模型、方法、论文写作。
- 工具：Python、MATLAB。
- 主要输出：数学建模论文、源代码、源数据。
- 工作偏好：优先直接执行；给出验证结果；无法自动化时明确资料和手动步骤。
- 项目推进偏好：开始新的题目或阶段前，先说明目标、方法、交付物和风险，等待确认后再继续；用户对后续工作不熟悉时不得把一次“继续”自动扩展为全部后续阶段授权。
- 知识库节点偏好：按知识实体的独立价值决定是否建节点，而不是机械追求“少节点”。完整赛题、论文复现、可独立调用的算法案例、具有独立来源与验证链的研究成果必须建立可见实体节点；没有独有知识的分类 Readme、空日报、占位文件和重复索引不建或删除。能够直接丰富现有权威笔记且不需要独立检索、复现或引用的内容，优先并入原节点。
- GitHub 同步偏好：知识库任务完成并通过必要验证后，默认自动提交并推送到 `origin/main`，无需每次重复询问；若工作区混有来源不明的修改、存在合并冲突、疑似密钥或隐私、大体积异常文件、远端分支异常或验证失败，则不得强行同步，必须先报告。禁止强制推送和改写历史。
- Token 使用偏好：长期工作按项目和阶段拆分为独立任务，以 Vault 中的 `Project-Status.md` 和权威笔记作为状态源，不继承或重复读取超长聊天历史；先搜索再按需读取相关片段，批量表达明确范围，优先复用已有 OCR、清洗稿、计算结果和图表说明。
- 写作偏好：结论先行，数学符号一致，图表可解释，来源可追溯，代码可复现；正文应达到知识库优秀论文的解释密度，每问形成“题意转换—模型建立—算法求解—结果分析—检验与边界”闭环，不能只写成压缩的求解报告。
- 可视化工具偏好：图形应服务于结论和证据链，不为覆盖图表清单而堆图。定量图优先使用当前可用且可复现的工具，默认采用 Python（NumPy、Pandas、Matplotlib）；MATLAB 可用于三维曲面、等高线、曲率、相图等。按题型和实际需要选用 Seaborn、Plotly、NetworkX、GeoPandas、Folium、scikit-learn、SHAP、UMAP、Origin、Visio/亿图图示、PPT 或 Illustrator。
- 缺失软件处理偏好：软件或库未安装、当前环境不可调用时，先用已有工具完成可复现替代，不自行安装，等待用户后续安装。定量图保留代码与源数据，手工示意图保留可编辑源文件。

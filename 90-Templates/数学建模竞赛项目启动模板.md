# 数学建模竞赛项目启动模板

> [!summary] 用途
> 用于正式赛题或完整模拟赛的初始化。每道题只建立一个项目现场，以 `Project-Status.md` 作为唯一状态源；聊天记录不承担交接。

## 项目目录

```text
06-Projects/<年份-赛事-题号-短标题>/
├─ Project-Status.md
├─ Readme.md
├─ Data/
│  ├─ Raw/                 # 原始数据，只读
│  ├─ Derived/             # 可由脚本重新生成的派生数据
│  └─ Readme.md            # 来源、字段、单位、质量与处理规则
├─ Code/
│  ├─ Readme.md            # 环境、入口、参数、输入输出和复现命令
│  ├─ src/
│  ├─ tests/
│  └─ outputs/             # 由代码生成的表格、图和日志
└─ Paper/
   ├─ Readme.md            # 论文版本、证据入口和提交清单
   ├─ figures/
   └─ submission/
```

不提交缓存、虚拟环境、密钥、隐私数据或无必要的大体积中间文件。原始数据、原题、原论文和附件不可覆盖。

## 目标与验收标准

- 回答全部子问题；
- 核心结果可由本项目代码复现；
- 模型、代码、图表、论文和附件数值一致；
- 检验能够支持结论并说明不支持的结论；
- 匿名、格式、页数、文件名、附件和提交方式符合当届官方要求；
- 完成最终上传并保存回执。

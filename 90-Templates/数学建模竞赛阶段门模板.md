## 五个人工确认关口

- [ ] **选题**：理解程度、时间、数据和实现风险可以接受；
- [ ] **假设**：现实合理性、影响和失效边界已经说明；
- [ ] **主模型**：有简单基线、选择理由和失败退路；
- [ ] **核心结果**：真实运行、可复现、单位与范围合理；
- [ ] **最终提交**：论文、代码、附件、匿名和平台回执无误。

## 独立审稿分级

| 等级 | 定义 | 处理规则 |
|---|---|---|
| P0 致命 | 漏答题、错误模型、不可行解、伪造或无法复现、违反提交规则 | 提交前必须关闭 |
| P1 重要 | 证据不足、检验薄弱、公式代码不一致、关键图表或引用问题 | 优先修复；不能修复则披露 |
| P2 一般 | 表述、排版、局部可读性和非核心改进 | 时间允许时处理 |

## 提交前四层审计

### 1. 问题层

- [ ] 全部子问题均有直接答案；
- [ ] 摘要中的方法和数字能在正文定位；
- [ ] 结论没有超出模型与数据支持范围。

### 2. 数学层

- [ ] 假设、变量、单位、索引、公式、目标和约束一致；
- [ ] 每个核心公式有来源、推导或题意解释；
- [ ] 数值算法说明初始化、参数、容差和停止条件。

### 3. 证据层

- [ ] 关键数字可追到数据、代码、参数、日志和输出；
- [ ] 图表由代码生成并含标题、轴、单位、图例和来源；
- [ ] 已完成与模型匹配的基线、误差或稳健性检验；
- [ ] 非代码作者已独立复跑核心结果。

### 4. 交付层

- [ ] 当届格式、匿名、页数、文件名、引用和附件要求已核对；
- [ ] 最终 PDF、源代码和支撑材料属于同一冻结版本；
- [ ] 首次上传留有故障缓冲；
- [ ] 已保存平台回执、时间和最终版本标识。

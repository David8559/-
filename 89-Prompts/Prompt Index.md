# Prompt Index

当前没有通过真实任务验收的可复用 Prompt，因此不为 Research、Workflow、Automation、Content 等空分类创建节点。

新 Prompt 使用 [[Prompt Template]]，必须包含：

1. 目标与适用场景；
2. 必要输入和不可缺失的信息；
3. 来源、权限与安全约束；
4. 输出结构和验收标准；
5. 至少一次真实任务的验证记录；
6. 版本号与已知失败情形。

只有满足上述条件的 Prompt 才进入本索引。分类使用 YAML 标签，不再使用空文件夹 Readme。
